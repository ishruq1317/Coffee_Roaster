---

## 🌟 Key Features

- **Asymmetrical 12-Column Editorial Hero:** `100dvh` responsive magazine layout with glassmorphic cards and shimmer skeleton loaders.
- **Interactive 6-Axis SVG Flavor Radar:** Tactile sensory profile polygon (Acidity, Body, Sweetness, Floral/Fruit, Cocoa/Nut, Spice Finish) synchronized with 4 roast levels.
- **Isolated 3D Perspective Producer Cards:** Staggered showcase of 6 single-origin micro-lots (*Colombia Finca El Paraíso, Ethiopia Halo Beriti, Panama Boquete Geisha, Kenya Kirimara AA, Brazil Fazenda, Guatemala*) responding to mouse pointer tilts (`rotateX`, `rotateY`).
- **Drag-to-Slide Roast Comparer:** Hardware-accelerated CSS `clip-path` split-screen comparison between *Light Nordic Filter Roast* (202°C, 11.5% dev) and *Full City Espresso Roast* (214°C, 16.8% dev).
- **Online Mini-Store & Interactive Cost Calculator:** Tactile switches for bag weights (`250g`, `500g -8%`, `1kg -15%`), grind settings, subscription toggle (`-12%`), and live monthly/annual savings calculator vs. cafe cups.
- **3-Step Slide-Out Click & Collect Drawer:** Cart review $\rightarrow$ 30-min pickup slot & address picker $\rightarrow$ live QR pickup pass and Google Maps route trigger.
- **EU Regulatory Compliance & Dock:** WhatsApp Barista direct trigger, phone dialer, GDPR cookie banner with granular preference toggles, and modals for **Impressum (TMG § 5)**, **Privacy Policy (GDPR)**, and **Terms of Service (AGB)**.
- **Trilingual & Multi-Currency:** Live reactive toggles for **EN / DE / FR** and **€ / £ / CHF**.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/ishruq1317/Coffee_Roaster.git

# Enter workspace
cd Coffee_Roaster

# Install dependencies
npm install

# Run development server
npm run dev

# Run production build
npm run build
```
